# AIcuNet

**AIcuNet** — децентрализованная сеть со встроенным AI-слоем, который рассчитан на работу на мощностях самой сети
(подход DePIN: участники отдают сети CPU / RAM / хранилище / GPU).

- **Сеть:** AINET — L1-блокчейн
- **Монета:** Axinit (тикер **AXNT**, знак ∀)
- **Кредиты вычислений (планируются):** **CuJoule (CuJ)** — для оплаты ресурсов и AI

## Идея
Блокчейн, который можно запустить почти на любом устройстве, без центрального оператора, —
децентрализация публичных блокчейнов, расширенная на AI и приложения:
- незаблокируемые приложения (например, мессенджер, который никто не может заблокировать, доступный в любой стране);
- относительно бесплатный AI-чат, который становится мощнее по мере роста вычислительной мощности сети;
- хранение данных и вычисления распределены по сети, а не на серверах одной компании.

## Статус — ранний этап
- **Фаза 1 (консенсус L1): работает** — блоки по тайм-слотам (3 с), единая цепь, подключение публичных
  нод без общего ключа.
- **Фаза 2 (ресурсный слой):** децентрализованное хранилище + proof-of-resource — в роадмапе.
- **Фаза 3 (GPU + AI-чат на мощностях сети):** в роадмапе.

Это ранняя сеть — возможны шероховатости.

## Как это работает (кратко)
- **Time-driven PoW:** время делится на 3-секундные слоты; слот = один блок. В слоте побеждает кандидат с
  наибольшим PoW; проигравшие отбрасываются до записи в цепь → единая цепь.
- **Memory-hard майнинг:** алгоритм майнинга RAM-зависимый, поэтому аренда специализированного железа для
  атаки менее практична.
- **Транзакции без комиссий:** вместо комиссий — механизм приоритета.
- **Смарт-контракты и dApps (Web3):** движок смарт-контрактов на JavaScript, интерфейсы dApp,
  хранящиеся в цепи, и собственные токены уже в коде сети; открыть их разработчикам — ближайший
  шаг роадмапа. Первое приложение сети — «Час майнера» — работает в сети с 30 сентября 2026 года
  в пробном режиме.

## Запустить ноду
Установить Node.js 22 (64-бит), получить код, выполнить `npm ci` в папке `Source` и запустить ноду из неё: `node run-ainet.js`.
Нужны две переменные окружения:
- `AINET_START_DATE=1783867255035` — время генезиса сети AINET (стартовая проверка `Source/core/ainet-guard.js`
  не пропустит другое значение);
- `AINET_SEEDS=ip:port,ip:port` — seed-ноды для подключения; актуальный список приходит вместе с приглашением
  (см. aicunet.com).
Майнинг memory-hard (CPU + RAM). Пошаговая инструкция по установке ноды готовится.
Майнинг по умолчанию выключен. Перед включением укажите счёт для награды, которым владеете вы
(панель майнинга в кошельке).
